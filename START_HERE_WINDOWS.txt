ИСПРАВЛЕНИЕ ПРОБЛЕМЫ С 12 СТРОКАМИ

1. В старом отчете все строки имеют НЕИЗВЕСТНО. Но в этом архиве
   входной Excel корректно распознается: 12 из 12 строк проходят отбор.
   Значит, скорее всего, в браузере запущен СТАРЫЙ сервер.
2. Закройте ВСЕ окна cmd, где запущен ou_processor.web.
3. В Windows PowerShell выполните:
   netstat -ano | findstr :8765
   Если остался LISTENING, найдите PID справа и завершите СВОЙ процесс:
   taskkill /PID <PID> /F
4. Распакуйте ЭТОТ ZIP в НОВУЮ папку.
5. Откройте cmd в папке reinziniring-pd-main, затем:
   python -m pip install -r requirements.txt
   python -m ou_processor.web
6. Откройте http://127.0.0.1:8765 и нажмите Ctrl+F5.
7. В интерфейсе должен быть заголовок «Ручная проверка · версия 2.1».
   Если его нет — работает старый сервер/кэш браузера.
8. Загрузите Тестовые_учреждения_исправлено.xlsx.

ВАЖНО: без реестра и без ручного запроса DaData настоящих кандидатов
с ИНН не будет. Нельзя подтверждать придуманные ИНН.
