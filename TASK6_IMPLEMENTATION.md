# Реализация задачи № 6

## Что изменено

1. Итоговый Excel содержит лист **«Письма»**: готовые к печати письма и письма, которым нужна проверка, находятся на одном листе и различаются по столбцу «Готовность».
2. Добавлен лист **«Ручная проверка»**. В нём объединены:
   - неоднозначные сопоставления учреждений и до трёх кандидатов;
   - письма с незаполненными или противоречивыми данными;
   - запросы DaData с ошибками и пропусками.
3. Лист **«Сводка»** дополнен статистикой дублей, исключений, статусов сопоставления, заполнения четырёх целевых полей и отдельных проверок DaData.
4. Для каждого исходного `.xlsx` создаётся отдельная копия в `filled_sources/`. В копии заполняются:
   - «Полное название ОУ в именительном падеже»;
   - «Название ОУ в родительном падеже»;
   - «Адрес»;
   - «Индекс».
5. Исходная книга не перезаписывается. Остальные листы и ячейки копии сохраняются. Если целевой колонки нет, она добавляется в строку заголовков. Пустые или конфликтные результаты не затирают исходное значение.
6. Точные дубли, удалённые перед обработкой, также получают заполненные значения в соответствующих строках копии исходной книги.
7. Старый лист «Проверить» оставлен для совместимости с прежними сценариями; расширенная очередь находится в «Ручная проверка».
8. Книга с формулами не копируется: сохранённые результаты вычислений могут пропасть при пересохранении через openpyxl. Ошибка указывается в сводке, а результат UI отмечается как частичный.

## Где искать результат

После запуска полного прогона:

- `schools.xlsx` — сводный отчёт;
- `filled_sources/` — заполненные копии исходных книг;
- `result.json` — подробные данные обработки.

В веб-режиме эти файлы сохраняются в `ui_runs/<код запуска>/result/`. Кнопка веб-интерфейса в текущей версии скачивает `schools.xlsx`; доступ к отдельным копиям из интерфейса относится к следующей задаче по доработке UI.

## Запуск

```bash
python -m pip install -r requirements.txt
python -m ou_processor.full_run input.xlsx --output run_all --cache dadata_cache.json
```

Для новых запросов DaData добавьте `--online` и задайте `DADATA_API_KEY` либо используйте `--ask-token`. Без `--online` используются доступные локальные данные и кэш.

## Проверки

Добавлены тесты на:
- заполнение четырёх колонок в отдельной копии;
- сохранение значений на других листах;
- добавление недостающих целевых колонок;
- заполнение строк, которые были удалены как точные дубли;
- структуру итогового Excel и статистику DaData.

Полный набор: **153 теста пройдены** в тестовой среде. Для запуска в обычном окружении установите зависимости из `requirements.txt`.
