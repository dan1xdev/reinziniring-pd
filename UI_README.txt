ИНТЕРФЕЙС И КОМАНДНАЯ СТРОКА

Проверено на Python 3.12. После установки зависимостей:
  python -m ou_processor.web
На macOS можно открыть «Запустить UI.command».
Откроется http://127.0.0.1:8765. Терминал должен оставаться открытым.
Остановка — Ctrl+C. Для другого порта: --port 8766.

1. Выберите или перетащите до 10 файлов .xlsx общим размером до 100 МБ.
2. Для каждой книги выберите рабочий лист или автоматическое определение.
3. Укажите ключ DaData при наличии и нажмите «Обработать по ТЗ».
   Без ключа проверка ограничивается локальными источниками с предупреждением.
4. Дождитесь завершения и скачайте Excel и журнал обработки.

Прогресс показывает выполненные шаги. При ошибке выбора листа или формата
выводится понятное сообщение. Одновременно выполняется одна задача.
Можно отменить обработку: файлы и частичный результат запуска удаляются.
Текущий запрос DaData может завершиться по таймауту
перед отменой.

Обработка использует реестр лицензий, затем автоматически подключает DaData
с настроенным ключом. По найденному ИНН уточняются адрес и статус;
без надёжного результата реестра кандидаты передаются оператору.
Конфликт ИНН отменяет автоматический выбор. Реестр аккредитации доступен
только при allow_accreditation_fallback: true в конфигурации.

ПОДКЛЮЧЕНИЕ DADATA

Ключ используется основной кнопкой «Обработать по ТЗ». Его можно ввести
в настройках, сохранить в системном хранилище или использовать до остановки
сервера. Если сохранить ключ не удалось, снимите флажок сохранения.
Альтернатива — --ask-token при запуске UI или переменная DADATA_API_KEY.
Кнопка «Обработать с DaData» дополнительно требует наличие ключа.
Без ключа обработка продолжается по локальным источникам с предупреждением.

Успешные ответы используются из кэша. ФИО и номера дел в API не передаются.
Ключ не включается в API-ответы и журналы. Без подтверждения действующего
юридического лица запись остаётся на проверке.

РЕЕСТР И ХРАНЕНИЕ

UI проверяет обновление реестра в фоне и сохраняет предыдущий снимок при сбое.
Статус, попытки и кнопка повтора доступны на странице.
Обновить отдельно:
  python -m ou_processor.registry update
  python -m ou_processor.license_registry update
Регулярное обновление вне UI настраивается отдельно в системном планировщике.
Подробнее: REGISTRY_README.txt.

Результаты: ../ui_runs/<код запуска>/result/schools.xlsx
Заполненные копии входных книг: ../ui_runs/<код запуска>/result/filled_sources/
Ссылки на копии доступны после обработки рядом со ссылкой на итоговый Excel.
В заполненных копиях сохраняются формулы, кэш вычислений и служебные листы.
Ошибки заполнения копий видны в сводке и интерфейсе.
Полный локальный результат: там же result.json
Журнал причин, источников и статусов: там же processing_log.json
Кэш ответов DaData: ../ui_cache/dadata.json
Реестр: ../registry_cache/
Реестр лицензий: ../license_registry_cache/

После перезапуска старые ссылки UI недоступны, файлы остаются на диске.
Очистка старых запусков выполняется пользователем.
Сервер слушает только 127.0.0.1 и рассчитан на одного пользователя.

Параметры UI:
  --port 8766         Другой локальный порт
  --registry ПАПКА   Снимки реестра
  --licenses ПАПКА   Снимки основного реестра лицензий
  --storage ПАПКА    Входные файлы и результаты
  --cache ФАЙЛ       Кэш ответов DaData
  --no-browser       Не открывать браузер автоматически

КОМАНДНАЯ СТРОКА

  python -m ou_processor input.xlsx --list-sheets
  python -m ou_processor input.xlsx --sheet "Рабочий лист" --output run_all
  python -m ou_processor input.xlsx --output run_all --ask-token

Можно использовать python -m ou_processor.full_run с теми же параметрами.
Можно передать несколько файлов. --sheet задаёт имя листа для всех книг.
Для разных листов разных книг используйте UI. --output — новая/пустая папка.
--config задаёт правила, --licenses — основной снимок, --registry — дополнительный.
--cache хранит ответы DaData. Ключ DADATA_API_KEY читается автоматически;
--ask-token запрашивает ключ без отображения ввода. --check-dadata и --online
сохранены для совместимости: запускают тот же каскад и требуют ключ.

Коды завершения: 0 — результат готов (ручная очередь возможна),
1 — ошибка обработки, 2 — ошибка или пропуск запроса DaData.

ОСТАВШИЕСЯ ЗАВИСИМОСТИ

Импорт ручных решений ожидает отдельный модуль.
Заполнение копий исходной выгрузки работает; исходные файлы не изменяются.
