МИНИМАЛЬНЫЙ ИНТЕРФЕЙС ДЛЯ ОБРАБОТКИ EXCEL

После установки зависимостей откройте
«Запустить UI.command» двойным щелчком или выполните из папки проекта:
  python -m ou_processor.web

Откроется http://127.0.0.1:8765. Терминал должен оставаться открытым.
Остановить сервер: Ctrl+C в терминале. При занятом порте используйте уже
открытый интерфейс либо запустите с --port 8766.

1. Выберите или перетащите один или несколько файлов .xlsx.
2. Ключ DaData не обязателен: без него обычная обработка идёт по реестру
   лицензий Рособрнадзора, без обращений к DaData. Если хотите использовать
   DaData как вспомогательный источник, введите API-ключ в «Настройках
   подключения». При отмеченном флажке он сохранится в системном хранилище
   ключей после запуска обработки и будет подставляться при следующих запусках.
   Ключ не показывается на странице и не записывается в проект. Его можно
   удалить кнопкой в настройках. Если сохранить ключ не удалось, снимите
   флажок и используйте его только во время работы сервера.
3. Нажмите «Обработать таблицы» и дождитесь завершения.
   Во время обработки можно нажать «Отменить обработку». Текущий запрос к
   DaData завершается или дожидается таймаута, затем задача останавливается.
   Частичный результат и загруженные файлы отменённого запуска удаляются.
4. Скачайте Excel. В нём одна строка на ИНН, адрес, ФИО учеников, номера дел,
   отдельные листы со спорными случаями, исходными строками и журналом поиска.

Поддерживается до 10 файлов общим размером 100 МБ и до 5 000 строк за запуск.
Одинаковые файлы в одной загрузке учитываются один раз.
Обязательные колонки: «Образовательное учреждение» + «Вид образования»
(либо «Тип документа об образовании»). ФИО и номера берутся из исходных колонок;
программа не придумывает отсутствующие сведения. Подробнее о формате — README.txt.

Ключ можно задать на время работы сервера:
  python -m ou_processor.web --ask-token
Либо использовать переменную окружения DADATA_API_KEY. Эти способы действуют
только на время работы сервера; ключ из интерфейса можно сохранить отдельно.
Ключ не попадает в исходники проекта, журнал запросов или адрес страницы.

По умолчанию при первом запуске копируется кэш предыдущего полного прогона,
если рядом есть final_schools/dadata_cache.json. Кэш содержит только организации.
Режим «Использовать только сохранённые ответы и реестр» работает без новых
обращений к DaData; пропущенные запросы видны в результате, а не скрываются.
Чтобы получить свежие ответы, задайте новый путь --cache.

Все загрузки и результаты сохраняются локально в соседней папке ui_runs,
в отдельном подкаталоге на запуск. Их можно найти там после закрытия браузера.
После перезапуска сервера старые ссылки скачивания не действуют; сами файлы
остаются в ui_runs/<код запуска>/result/schools.xlsx. Удаление старых запусков
выполняется вручную. Кэш организаций находится в ui_cache/dadata.json.

Сервер слушает только 127.0.0.1. ФИО и номера дел не передаются во внешние
сервисы. Интерфейс рассчитан на локальную работу одного пользователя.
Одновременно выполняется одна обработка. При ошибках DaData доступен результат
резервного поиска с явным предупреждением о неполной проверке.

При запуске интерфейс в фоне проверяет оба реестра и загружает обновления:
реестр лицензий - по настройкам config.json (раздел license_registry,
поле update_days), резервный реестр аккредитации - по HTTP-заголовкам.
Статус и номер попытки видны в правой панели. При временной сетевой ошибке
выполняется до трёх попыток с паузами. Интерфейс продолжает работать; пока
идёт проверка, используется предыдущий локальный снимок. Ошибка загрузки
не удаляет его. Если снимка реестра лицензий ещё нет, учреждения уходят на
лист «Проверить» - ошибки не будет. После неудачных попыток нажмите
«Повторить загрузку реестра лицензий» или «Повторить загрузку резервного
реестра» без перезапуска.

Перенос на другой компьютер

Нужен Python 3.10+. Из папки prototype:
  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -r requirements.txt
  python -m ou_processor.web
На Windows активация: .venv\Scripts\activate
Большой резервный реестр не включён в ZIP. Интерфейс скачает его автоматически
при запуске. Можно также перенести папку registry_cache рядом с prototype.

Дополнительные параметры:
  --port 8766          Другой локальный порт
  --licenses ПАПКА    Путь к снимкам реестра лицензий
  --registry ПАПКА    Путь к готовому резервному реестру
  --storage ПАПКА     Папка входных файлов и результатов
  --cache ФАЙЛ        Кэш ответов DaData
  --no-browser        Не открывать браузер автоматически

Для отдельного обновления реестров из терминала:
  python -m ou_processor.license_registry update
  python -m ou_processor.registry update
Ежедневное обновление вне запущенного UI настраивается отдельно в планировщике.
